    转写文本刚被改过

    01 主角只有一个

    没有左导航、没有三栏。整屏只有一段稿子，视线从标题直落到正文，不被面板切碎。

    02 元信息变成批注

    时间码、校对状态、操作按钮移到右侧页边，主栏只剩字。像书上的旁注，不打断阅读。

    03 说话人写成剧本

    名字右对齐成一列，正文顶格成行；不用头像、不用气泡、不用框，扫一眼就知道谁在说。

    04 色彩克制

    暖白纸面 + 深墨字 + 一个靛青强调色；唯一暖色留给"待校对"这类真需要你动手的事。

    05 一段录音一种文体

    不是只有会议：会议纪要 / 速记卡 / 日记随笔 / 问答摘要由 LLM 自动判定，判错一键换；换文体还会连带改"要不要分离说话人"这类处理开关。
